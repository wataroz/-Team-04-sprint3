## Mapping ตาราง

| Feedback / Insight | Priority | สิ่งที่แก้ใน Sprint 5 | Owner |
|---|---|---|---|
| Mobile แคบ layout พัง | P0 | ทำหน้าจอให้ปรับตามขนาดมือถือทุกขนาด (320px ถึง iPad) + เพิ่มแถบเมนูล่างบนมือถือ (เหมือนแอปทั่วไป) + กราฟปรับสีให้ชัดบนจอเล็ก | BEST |
| LINE Bot ส่ง PDF ซ้ำ | P0 | กันบอทตอบซ้ำ — แต่ละข้อความตอบได้ครั้งเดียว + ถ้าตอบไม่ทันให้ส่งแบบ push (เด้งเข้าแชทแทน) + ลบรายการ PDF ที่ค้างอัตโนมัติ | WA |
| Parser ภาษาอังกฤษ + SCB ไม่ครบ | P1 | เพิ่มคำอ่าน statement ภาษาอังกฤษ (เช่น TRANSFER, PAYMENT) ในทุกธนาคาร + แก้รูปแบบ SCB ที่อ่านไม่ได้ | WA |
| ผู้ใช้ขอลบบัญชี/ขอข้อมูลส่วนตัว (PDPA — กฎหมายคุ้มครองข้อมูลส่วนบุคคล) | P0 | เพิ่มหน้า Settings + ปุ่มลบบัญชีแบบมีระยะผ่อนผัน 30 วัน + ปุ่มยกเลิกการลบ + ดาวน์โหลดข้อมูลตัวเองเป็น CSV ได้ | AJ + ACHI |
| โลโก้/ไอคอนไม่สวย + ติดตั้งเป็นแอปไม่ได้ | P1 | ออกแบบโลโก้ใหม่ (block M สีครีม/ทอง) + ทำชุดไอคอนครบทุกขนาด + ติดตั้งเป็นแอปบนมือถือได้ (PWA — เว็บที่ลงเครื่องได้เหมือนแอปจริง) + สลับธีมสว่าง/มืดได้ | BEST + ACHI |
| Login ด้วย email อย่างเดียว ไม่ปลอดภัย | P1 | เพิ่มปุ่ม "เชื่อมด้วย LINE" — กดครั้งเดียว LINE ยืนยันตัวตนให้ (เหมือน Login with Google) — ปลอดภัยกว่าพิมพ์ email เอง + คงคำสั่งเดิมเป็นทางสำรอง | WA |

---

## หลักการเลือก Priority

- **P0** = กระทบผู้ใช้โดยตรง ไม่แก้ไม่ได้ (mobile usability, PDPA compliance, ฟีเจอร์หลักพัง)
- **P1** = ปรับให้ดีขึ้น แต่ไม่ block ได้ (branding, security improvement)
- **P2** = nice-to-have, เก็บเป็น backlog
