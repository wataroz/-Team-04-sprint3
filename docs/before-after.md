# Before / After — Sprint 5 (Prototype v1 → v2)

> เปรียบเทียบความเปลี่ยนแปลงระหว่าง Prototype v1 (Sprint 4) และ Prototype v2 (Sprint 5)

**อัปเดต**: 2026-06-14

---

## 8 จุดเปรียบเทียบ

### 1. Mobile
- **v1**: layout พังที่ความกว้าง ≤768px, ไม่มี bottom nav, ปุ่มเล็กกดยาก
- **v2**: ปรับขนาดได้ทุกหน้าจอ 320px ขึ้นไป + bottom nav อัตโนมัติบนมือถือ ≤1024px + ปุ่มขนาด 44px ตามมาตรฐาน touch target

### 2. LINE Bot
- **v1**: ส่ง PDF 1 ไฟล์อาจตอบ 2-3 ครั้งซ้ำ + ไม่รับ PDF ที่ใส่รหัสผ่าน
- **v2**: ตอบครั้งเดียวต่อข้อความ (reply token single-use) + รับ PDF ใส่รหัสผ่านได้ผ่าน chat (ใส่รหัส 3 ครั้ง, หมดเวลา 5 นาที, "ยกเลิก" ได้)

### 3. Parser
- **v1**:
  - KBank statement ภาษาอังกฤษ: อ่านได้ **0** รายการ
  - SCB statement: อ่านได้ **18** รายการ
- **v2**:
  - KBank statement ภาษาอังกฤษ: อ่านได้ **276** รายการ
  - SCB statement: อ่านได้ **45** รายการ

### 4. Web UX
- **v1**: ตั้งค่ากระจาย floating panel ลอยที่มุมขวาบน — ใช้ยาก ไม่รู้ว่ามีอะไร
- **v2**: หน้า Settings รวมศูนย์ 4 แท็บ (โปรไฟล์/การแสดงผล/LINE/แจ้งเตือน) + active tab indicator ชัดเจน + back button มุมซ้ายบน

### 5. Privacy / PDPA
- **v1**: ลบบัญชีไม่ได้, ดาวน์โหลดข้อมูลตัวเองไม่ได้ — ไม่ตรงกฎหมายคุ้มครองข้อมูลส่วนบุคคล
- **v2**: ลบบัญชีได้ (3-step modal: warning + Export CSV + พิมพ์ DELETE + ใส่ email) + ระบบพักไว้ 30 วัน + ยกเลิกการลบได้

### 6. Branding + PWA
- **v1**: โลโก้เดิม (wave M สีแชมเปญ) — ติดตั้งเป็นแอปไม่ได้
- **v2**: โลโก้ใหม่ (block M ครีม/ทอง) + favicon ครบทุกขนาด (16/32/64/96/180/192/256/512/1024) + Android Chrome ติดตั้งเป็นแอปได้ + ไอคอนขึ้น home screen เหมือนแอปจริง

### 7. Theme
- **v1**: ธีมเดียว (มืด)
- **v2**: สลับสว่าง/มืดได้ (toggle ☀️/🌙) + จำค่าในระบบ (database) → เปิดเครื่องอื่น ธีมเหมือนเดิม + แท็บสีของระบบ (meta theme-color) เปลี่ยนตามอัตโนมัติ

### 8. LINE Linking
- **v1**: พิมพ์ "เชื่อม email" ใน LINE bot — ไม่ verify ว่าผู้ส่งเป็นเจ้าของ email จริง (security gap)
- **v2**: ปุ่ม "เชื่อมด้วย LINE" 1 คลิก — LINE ยืนยันตัวตนจริง (ระบบเดียวกับ Login with Google) + คงคำสั่งเดิมเป็น fallback
